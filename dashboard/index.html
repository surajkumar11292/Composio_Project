🤖 What the Agent Does Autonomously

  • Generates 4 targeted queries per app (auth, docs, pricing, MCP)
  • Searches Tavily with search_depth="advanced" for each query
  • Falls back to Serper (Google SERP) if Tavily hits rate limits
  • Extracts structured JSON via Gemini with strict response schema
  • Validates output with Pydantic — auto-rejects malformed responses
  • Saves each app profile to data/raw/{app_id}.json (resumable)
  • Aggregates patterns, computes stats, generates this dashboard

👤 Where Humans Were Needed

  • Rate limit navigation — Free-tier Tavily has a 1,000/mo cap. After hitting it, manual fallback to Serper was configured
  • Gemini model selection — gemini-2.0-flash was deprecated mid-run; had to switch to gemini-1.5-flash then handle 404s
  • Verification sampling — Manually spot-checked 10 apps against real docs to validate agent accuracy
  • Edge cases — Gladly, Finix: no public docs page at all; agent flagged "Gated" correctly but needed human to confirm

🚀 Production Path: Composio MCP Gateway

This agent was built from scratch to prove it's possible — custom OAuth, rate limiting, Tavily integration, Pydantic validation, all of it. But that's the wrong approach for scale. Composio's MCP Gateway already ships all 100 of these integrations as production-ready tools with auth handled, schemas validated, and MCP protocol enabled. A senior engineer would build this research agent to understand the ecosystem, then point production AI agents directly at the MCP Gateway. That's the move.
