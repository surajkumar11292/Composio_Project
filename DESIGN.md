# Design System Guidelines

## Core Principles
1. **Zero-AI Slop**: No generic violet/purple themes, no cheap CSS text-clip gradients, and no unicode emojis in place of real SVG icons.
2. **Tabular Precision**: Numbers and metrics use tabular numerals (`font-variant-numeric: tabular-nums`) with clear alignment.
3. **High Information Density**: Built for executive skimmability and engineering scrutiny. Key findings and takeaways are plain, bold, and readable in 30 seconds.
4. **Bespoke Craft**: Drawn inline SVG iconography with crisp 1.5px stroke weights; styled scrollbars, styled `::selection`, and subtle interactive states.
